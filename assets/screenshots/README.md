# Screenshots

Add project screenshots and UI captures here.

## Naming Convention

Use descriptive, lowercase filenames with underscores:

```
dashboard_overview.png
analysis_upload.png
analysis_result.png
alert_management.png
settings_thresholds.png
login_page.png
api_docs.png
```

## Recommended Screenshots

| Screenshot | Description |
|-----------|-------------|
| `dashboard_overview.png` | Main dashboard with stats, live call feed, and risk distribution |
| `analysis_upload.png` | Audio upload dropzone on the analysis page |
| `analysis_result.png` | Full analysis result with risk gauge, verdict, spectrogram, and waveform |
| `alert_management.png` | Alert table with filters and severity badges |
| `alert_detail.png` | Alert detail modal with acknowledge/resolve actions |
| `settings_thresholds.png` | Risk threshold configuration with spectrum preview |
| `settings_apikeys.png` | API key management panel |
| `api_docs.png` | API documentation page with code snippets |
| `login_page.png` | Login screen |
